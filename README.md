# ASAC Data Science Portfolio

## About

This repository showcases my practical projects completed during the Data Science bootcamp at Abdul Aziz Al Ghurair School of Advanced Computing (ASAC), part of Luminus Technical University College (LTUC).

The projects demonstrate my developing skills in data analysis, SQL, machine learning, business intelligence, and data storytelling.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [01 - Football Data Analysis](./01-sql-football-analysis) | Analysis of Jordan's international football performance, historical trends, and World Cup statistics. | SQL, BigQuery |
| [02 - Hotel Booking Analysis and Prediction](./02-hotel-cancellation-ml) | Predicting booking cancellations, estimating room prices, and identifying customer segments. | BigQuery ML, SQL |
| [03 - NYC Taxi Analytics Dashboard](./03-nyc-taxi-power-bi) | An interactive dashboard analyzing taxi demand, revenue, geographic patterns, and year-over-year changes. | Power BI, Power Query, DAX |

## Key Findings

- **Football analytics:** Analyzed Jordan's historical performance across 494 international matches.
- **Hotel analytics:** Analyzed 119,390 bookings and developed a cancellation prediction model with approximately 75.8% validation accuracy.
- **Taxi analytics:** Identified a 71.1% decline in sampled NYC yellow taxi trips in 2020 compared with 2019.
